# amazon-annotations recipe

このリポジトリは、完成済みのChrome拡張機能そのものを配布するためのプロジェクトではありません。

`specification.md` を生成系AIに渡し、Amazon.co.jpの商品ページにNG・メモ・保護表示を追加する自分用Chrome拡張機能を再構築するためのレシピを公開するプロジェクトです。

## プロジェクトの目的

このプロジェクトの目的は、成果物そのものではなく、成果物を再生成できる仕様書を共有することです。

対象とする成果物は、以下のようなChrome拡張機能です。

- Amazon.co.jpの商品詳細ページでASINを取得する
- popupからNG登録、コメント保存、保護フラグ設定を行う
- 商品詳細ページ上にNG、コメント、保護状態を表示する
- Amazon.co.jp検索結果ページ上で、保存済み商品の状態を表示する
- NG商品はグレーアウトする
- コメントあり商品は黄色枠と `メモあり` バッジで表示する
- 保護済み商品は青緑枠と `保護` バッジで表示する
- データは `chrome.storage.local` に保存し、外部送信しない
- options pageで保存件数、使用容量、JSONエクスポート/インポート、手動削除を扱う

このREADMEは、生成系AIで同等の拡張機能を作るための入口です。実装の正本は `specification.md` です。

## コア・アーキテクチャ

生成される拡張機能は、Manifest V3の素のHTML/CSS/JavaScript構成を想定しています。ビルドツールや外部ライブラリは前提にしません。

一覧ページの実装では、AmazonのDOM差異と負荷が詰まりどころになります。`specification.md` には、今回の試行錯誤から分かった注意点を含めています。

特に重要な方針は以下です。

- 一覧ページで全商品リンクを無制限に走査しない
- 保存済みでNG・コメント・保護のいずれかがあるASINだけを照合する
- まず「カートに入れる」導線を起点にASINと商品カードを特定する
- カート導線で取れない場合だけ、保存済みASINに限定して商品リンクやASIN属性を確認する
- `メモあり` バッジは商品名の後ろではなく、商品カード先頭側に表示する
- 拡張機能更新後は、Amazonタブ側もリロードする必要がある

## AIを使った再構築手順

1. 新しい作業ディレクトリを用意する
2. `specification.md` を生成系AIに渡す
3. 次のように依頼する

```text
specification.md に従って、Chrome Manifest V3 の拡張機能を実装してください。
ビルドツールは使わず、素のHTML/CSS/JavaScriptで作成してください。
READMEにはインストール方法、使い方、手動テスト手順を書いてください。
実装後、node --check と jq による確認も行ってください。
```

4. 生成された拡張機能をChromeで読み込む

```text
chrome://extensions/
  -> デベロッパーモードON
  -> パッケージ化されていない拡張機能を読み込む
  -> manifest.json が直下にあるフォルダを選択
```

5. Amazon.co.jpの商品詳細ページと検索結果ページで手動確認する

確認する観点:

- popupでASINが表示される
- NG登録・解除ができる
- コメント保存・編集・削除ができる
- 保護ON/OFFができる
- 詳細ページ上にNG、コメント、保護が表示される
- 検索結果ページ上にNG、メモあり、保護が表示される
- `メモあり` バッジhoverでコメントが表示される
- options pageで件数、容量、JSONエクスポート/インポートが動く

6. うまく動かない場合は、`specification.md` の「詰まりどころと対策」を参照して、生成系AIに修正依頼する

例:

```text
一覧ページでフリーズします。
specification.md の「一覧ページでフリーズする」の対策に従って、
全商品リンク走査を避け、保存済みASINだけを照合する実装に修正してください。
```

```text
メモありバッジがDOMにはありますが画面に見えません。
specification.md の「一覧ページでメモありがDOM上にあるのに見えない」の対策に従って、
商品カード先頭側にprependする実装に修正してください。
```

## ファイル構成

このリポジトリで公開する中心ファイルは以下です。

```text
README.md
specification.md
```

- `README.md`
  - このリポジトリの目的と、AIを使った再構築手順を説明する文書
- `specification.md`
  - 生成系AIに渡すための実装指示書
  - 機能要件、データ設計、DOM検出方針、詰まりどころ、検証手順を含む

手元の作業環境には、検証用に生成済みの `manifest.json` や `src/` が存在する場合があります。ただし、公開プロジェクトとしての主成果物は `README.md` と `specification.md` です。
